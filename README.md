# 🖥️ Hardware Monitor

Мощное десктопное приложение для мониторинга аппаратных ресурсов компьютера на платформе Windows, написанное на C# с использованием WPF и MVVM архитектуры.

## 📋 Описание

Hardware Monitor — это профессиональный инструмент для мониторинга системных ресурсов Windows в реальном времени. Приложение предоставляет детальную информацию о процессоре, оперативной памяти, дисках, процессах и операционной системе с возможностью экспорта данных в различных форматах.

## ✨ Основные возможности

### 🔍 Мониторинг компонентов

- **💻 Процессор (CPU)**
  - Модель и производитель
  - Количество физических ядер и логических потоков
  - Текущая частота работы
  - График загрузки в реальном времени
  - Процент использования

- **🧠 Оперативная память (RAM)**
  - Общий объем и использование
  - Детальная информация о каждом модуле памяти
  - Производитель, объем и частота планок
  - Процент загруженности

- **💾 Накопители**
  - Список физических дисков
  - Информация о разделах (буква, размер, свободное место)
  - Файловая система
  - Процент занятости каждого раздела

- **🖥️ Операционная система**
  - Название и версия Windows
  - Номер сборки
  - Разрядность системы
  - Имя компьютера и текущий пользователь

- **⚙️ Диспетчер процессов**
  - Список всех запущенных процессов
  - PID, имя процесса, статус
  - Использование CPU и RAM для каждого процесса
  - Возможность завершения процессов
  - Автоматическое обновление списка

### 📊 Визуализация

- График загрузки процессора в реальном времени (80 точек истории)
- Направляющие линии для удобства чтения графика
- Анимированное заполнение под графиком

### 💾 Экспорт данных

Поддержка трех форматов экспорта:

- **📄 TXT** — структурированный текстовый отчет
- **📋 JSON** — данные в формате JSON для интеграции
- **📊 CSV** — табличные данные для анализа в Excel
- **🎨 PNG** — сохранение графика загрузки CPU

Возможность экспорта во все форматы одновременно!

### 🔄 Автоматическое обновление

- Обновление данных каждые 2 секунды
- Сохранение выбранного процесса при обновлении
- Умное обновление списка процессов без мерцания

## 🏗️ Архитектура

Проект построен по паттерну **MVVM (Model-View-ViewModel)**:

```
HardwareMonitor/
│
├── Models/                     # Модели данных
│   ├── CpuData.cs             # Данные процессора
│   ├── RamData.cs             # Данные оперативной памяти
│   ├── OsData.cs              # Данные ОС
│   ├── StorageData.cs         # Данные накопителей
│   └── TaskItem.cs            # Модель процесса
│
├── Services/                   # Бизнес-логика
│   ├── CpuService.cs          # Сбор данных CPU
│   ├── RamService.cs          # Сбор данных RAM
│   ├── OsService.cs           # Сбор данных ОС
│   ├── StorageService.cs      # Сбор данных дисков
│   └── TaskService.cs         # Управление процессами
│
├── ViewModels/                 # Слой представления
│   ├── AppViewModel.cs        # Главная ViewModel
│   ├── ViewModelBase.cs       # Базовый класс ViewModel
│   └── DelegateCommand.cs     # Реализация ICommand
│
└── Views/                      # UI
    └── MainWindow.xaml        # Главное окно приложения
```

## 🛠️ Технологический стек

- **Платформа:** .NET Framework 4.7.2+
- **UI:** WPF (Windows Presentation Foundation)
- **Архитектура:** MVVM
- **Сбор данных:** WMI (Windows Management Instrumentation)
- **Управление процессами:** System.Diagnostics

## 📦 Требования

- **ОС:** Windows 7 / 8 / 10 / 11
- **.NET Framework:** 4.7.2 или выше
- **Разрядность:** x86 / x64
- **Права:** Администратор (для завершения некоторых процессов)

## 🚀 Установка и запуск

### Клонирование репозитория

```bash
git clone https://github.com/yourusername/hardware-monitor.git
cd hardware-monitor
```

### Сборка проекта

**Через Visual Studio:**
1. Откройте `HardwareMonitor.sln`
2. Выберите конфигурацию `Release`
3. Нажмите `Build > Build Solution`
4. Запустите `bin/Release/HardwareMonitor.exe`

**Через командную строку:**
```bash
msbuild HardwareMonitor.sln /p:Configuration=Release
```

## 💡 Использование

### Основные функции

1. **📊 Просмотр системной информации**
   - При запуске автоматически загружаются все данные
   - Обновление происходит каждые 2 секунды

2. **🔄 Ручное обновление**
   - Кнопка `Обновить` или `F5`
   - Принудительное обновление всех данных

3. **📁 Экспорт отчета**
   - `Файл → Сохранить отчет`
   - Выберите формат: TXT, JSON, CSV или все сразу

4. **📈 Сохранение графика**
   - `Файл → Сохранить график`
   - График сохраняется в формате PNG

5. **❌ Завершение процессов**
   - Выберите процесс из списка
   - Нажмите `Завершить процесс` или дважды кликните
   - Подтвердите действие

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `F5` | Обновить данные |
| `Ctrl+S` | Сохранить отчет |
| `Ctrl+G` | Сохранить график |
| `Delete` | Завершить выбранный процесс |

## 🏆 Особенности реализации

### Оптимизация производительности

- **Асинхронный сбор данных** — все тяжелые операции выполняются в фоновых потоках
- **Умное обновление UI** — обновляются только изменившиеся данные
- **Кэширование CPU времени** — для точного расчета процента использования
- **Очистка ресурсов** — автоматическое освобождение памяти WMI объектов

### Обработка ошибок

- Graceful degradation при недоступности WMI
- Защита от сбоев при чтении защищенных процессов
- Информативные сообщения об ошибках
